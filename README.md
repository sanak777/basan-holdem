# 바카라산악회 홀덤 v1.2

샘플 영상의 초록색 테이블을 참고해 만든 회원용 텍사스 홀덤입니다. 최대 10명이 각자 휴대폰에서 같은 방에 접속합니다. 채팅 기능은 없습니다. 현금 결제·충전·환전 기능 없이 가상칩으로만 진행합니다.

## GitHub에 올리기

1. ZIP 압축을 풉니다.
2. GitHub에서 새 저장소를 만듭니다. 이름 예: `basan-holdem`.
3. 저장소 화면에서 **Add file → Upload files**를 누릅니다.
4. 압축을 푼 폴더 **안의 파일과 public, test 폴더**를 올립니다. ZIP 파일 자체를 올리지 마세요.
5. 저장소 첫 화면에 `package.json`, `server.js`, `poker.js`, `render.yaml`, `public`이 보이는지 확인합니다.
6. **Commit changes**를 누릅니다.

## Render 배포 설정

Render에서 **New → Web Service**를 선택하고 위 저장소를 연결합니다. 실시간 게임 서버가 필요하므로 Web Service로 배포합니다.

| 항목 | 입력값 |
|---|---|
| Name | `basan-holdem` (사용 가능한 이름) |
| Language / Runtime | `Node` |
| Branch | `main` |
| Root Directory | 비워두기 |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | `Free` |
| Health Check Path | `/health` |

Environment Variables에 아래 값을 넣습니다.

| Key | Value |
|---|---|
| `ADMIN_PASSWORD` | `8959` |
| `NODE_VERSION` | `22` |

**Deploy Web Service**를 누르고 완료 후 표시되는 `https://...onrender.com` 주소로 접속합니다. `PORT`는 Render가 지정하는 값을 서버에서 자동으로 사용합니다.

`render.yaml`로 Blueprint 배포를 하는 경우에도 `ADMIN_PASSWORD` 입력란에 `8959`를 넣으세요. 환경변수를 따로 넣지 않은 로컬 실행의 초기 비밀번호도 `8959`입니다.

공식 배포 안내: https://render.com/docs/web-services

## 방장 사용 순서

1. 사이트 첫 화면에 닉네임을 입력합니다.
2. **방장 로그인 · 새 방 만들기**를 누릅니다.
3. 비밀번호 **8959**로 로그인합니다.
4. 상단의 **방 코드 ↗** 버튼으로 입장 링크를 공유합니다. 방 코드는 영어 없이 숫자 4자리(예: 1234)로 자동 생성됩니다.
5. 회원들이 입장하고 빈 좌석을 눌러 착석합니다. 방장도 좌석에 앉아 참여하거나 관전할 수 있습니다.
6. 2명 이상 착석하면 방장이 상단 **게임 시작**을 누릅니다.
7. 각 판 정산 후 8초 뒤 다음 판이 자동 시작됩니다.

상단의 작은 **ADMIN 배너와 시작·종료 버튼은 로그인한 방장에게만 보입니다.** 일반 참가자에게는 표시되지 않으며, 서버에서도 관리자 권한을 검사합니다.

| 방장 버튼 | 동작 |
|---|---|
| 게임 시작 | 첫 판 시작 및 다음 판 자동 진행 |
| 현재 판 후 종료 | 현재 판의 베팅과 승패 정산은 끝까지 진행하고 다음 판은 시작하지 않음 |
| 즉시 종료 | 현재 판을 취소하고 현재 판에 낸 베팅칩 전부 반환 |
| ADMIN 배너 | 블라인드·시작칩·차례 제한시간 설정 창 |
| 전체 칩 초기화 | 게임 종료 상태에서 모두의 칩을 시작칩으로 초기화 |
| 관리자 로그아웃 | 관리 배너를 숨기고 관리자 권한 해제 |

블라인드는 상단 **블라인드 조정**에서 진행 중에도 예약 변경할 수 있으며 다음 판부터 적용됩니다. 그 밖의 설정은 게임 종료 후 변경할 수 있습니다. 시작칩 설정은 새 참가자에게 적용되며, 기존 참가자도 같게 맞추려면 **전체 칩 초기화**를 누릅니다.

기존 방에 다시 방장으로 로그인하려면, 해당 방에 입장한 뒤 **게임 기록 → 방장 로그인**을 사용합니다. 비밀번호로 로그인한 계정이 현재 방장이 됩니다. 한 방에서는 가장 최근에 관리자 로그인한 한 사람만 관리할 수 있습니다.

## 참가자 사용 순서

1. 받은 링크를 열어 닉네임을 입력하고 입장합니다. 링크에는 방 코드가 자동 입력됩니다.
2. 빈 좌석을 눌러 착석합니다. 기본 칩은 100,000, 블라인드는 3,000 / 6,000입니다.
3. 자기 차례에 **폴드 / 체크·콜 / 레이즈 / 올인**을 선택합니다.
4. 레이즈 입력값은 **이번 베팅 라운드의 총 베팅칩**입니다. 예를 들어 이미 500칩을 냈을 때 2,000을 입력하면 1,500칩을 추가로 냅니다.
5. 자기 카드는 하단에 보이고, 다른 사람의 카드는 쇼다운 전까지 비공개입니다. 방장에게도 다른 사람의 비공개 카드를 전달하지 않습니다.

좌석을 바꿔도 같은 입장 정보에서는 보유칩을 유지합니다. 판 진행 중 착석한 사람은 다음 판부터 참여합니다. 자리비움 상태에서는 다음 판 카드를 받지 않으며, 복귀 버튼으로 해제할 수 있습니다.

기본 제한시간은 30초입니다. 시간이 끝나면 추가 베팅 없이 가능한 경우 자동 체크, 콜이 필요하면 자동 폴드합니다. 시간 초과한 사람은 자리비움 상태가 됩니다. 진행 중 자리에서 일어나거나 방을 나가면 그 판 이후 좌석이 비워집니다.

## 포함된 게임 규칙

- 텍사스 홀덤: 개인 카드 2장, 플롭 3장, 턴 1장, 리버 1장.
- 노리밋 베팅, 블라인드 자동 납부, 헤즈업 순서, 딜러 버튼 이동.
- 7장 중 가장 높은 5장 족보와 키커로 승패 결정.
- 올인 금액별 메인팟·사이드팟 개별 정산, 매칭되지 않은 칩 반환.
- 동점 분배와 남는 1칩은 딜러 왼쪽의 해당 승자부터 배분.
- 불완전한 올인 레이즈 이후 재레이즈 가능 여부 검사.
- 새로고침 후 같은 브라우저 탭의 입장 정보를 사용해 다시 연결.

## 운영 범위

이 버전은 방·칩·입장 정보를 서버 메모리에 보관합니다. 서버 재시작, 재배포, 무료 서비스 휴면 후 재시작 시 초기화되므로 방장이 새 방을 만들어야 합니다. 영구 회원 계정이나 칩 저장 기능은 포함하지 않습니다. 한 개의 서버 인스턴스로 운영하세요.

Render Free 서비스는 요청이 없는 상태로 15분이 지나면 휴면에 들어갈 수 있고, 다시 접속할 때 기동을 기다릴 수 있습니다. https://render.com/docs/free

## PC 로컬 실행

Node.js 22 이상을 설치한 뒤 이 폴더에서 실행합니다.

```sh
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 열어 사용합니다. HTML 파일을 직접 더블클릭해서 열면 멀티플레이 서버에 연결되지 않습니다.

## 검증

```sh
npm test
```

족보·키커, 헤즈업 순서, 최소 레이즈, 불완전·누적 올인, 사이드팟, 동점·홀수칩, 중복 요청 차단, 시간 초과, 칩 보존, 비공개 카드 필터, 관리자 로그인과 권한 검사를 포함합니다. 별도의 외부 Node 패키지 없이 실행됩니다.

납품 시 16개 검사를 통과했습니다. 배포된 클라이언트 코드로 방장과 두 참가자의 생성·입장·착석·시작·체크/콜·쇼다운·종료 흐름도 서버와 함께 검사했습니다. 단, 이 환경에서는 브라우저 실행에 필요한 파일을 내려받을 수 없어 실제 브라우저 렌더링·터치 화면 검증은 수행하지 못했습니다. 배포 후 서로 다른 휴대폰에서 입장해 화면과 조작을 확인해주세요.
